# 감염 경로 관리 프로그램 (Infection Path Tracker)

## 프로젝트 개요
- **과목**: 전자공학도를 위한 프로그래밍 기초 (2022 기말 프로젝트)
- **목적**: 가상의 감염병(COVID-59) 상황을 가정해, 환자 정보와 도시 간 이동 이력을 바탕으로 감염 경로를 추적하고 최초 전파자를 찾아내는 C 프로그램 구현
- **언어**: C

## 문제 설정
- 전 세계 40개 도시 중 매일 다른 도시로 이동하는 환경에서, 전염력이 매우 강한 감염병이 발생했다고 가정
- 감염자는 발병 당일 또는 전날, 같은 시점·같은 도시에 있던 사람에게 반드시 전염시킴
- 각 환자 정보(번호, 나이, 감염 확인일자, 최근 5일간 이동 장소)를 파일로 입력받아 프로그램 내에서 관리

## 주요 기능
1. 특정 환자 번호를 입력받아 상세 정보(나이, 확인일자, 최근 5일 이동 장소) 출력
2. 특정 장소에서 발병이 확인된 환자 목록 출력
3. 특정 나이 범위에 해당하는 환자 목록 출력
4. 감염 경로 추적 — 지정한 환자를 시작으로 전파자를 순차적으로 추적해, 시점·장소와 함께 출력하고 최초 전파자를 최종적으로 도출

## 설계 내용
- 과제에서 주어진 base code 구조를 따르며, 파일별 역할을 명확히 분리 (Data Encapsulation)
  - `ifct_element.c/.h`: 환자 정보 구조체 정의 및 생성, 내부 데이터 접근 함수 제공 (구조체 정의는 이 파일 내에서만 사용 가능)
  - `ifct_database.c/.h`: 환자 정보를 linked list로 저장·관리 (다른 파일은 반드시 header에 정의된 함수를 통해서만 접근)
  - `main.c`: 파일 입출력, 메뉴 흐름 제어, 표준 입출력을 전담 (다른 소스 파일은 표준 입출력을 직접 다루지 않음)
- 소스 파일 간 전역 변수 공유 금지(`extern` 미사용), include 관계도 계층 규칙을 지켜 설계
- 감염 경로 추적(`trackInfester`, `isMet` 함수)은 두 환자의 이동 이력을 비교해, 감염 가능 시점에 동일 장소에 있었는지를 판별하고 가장 이른 전파자를 찾는 방식으로 구현

## 실행 방법
```
./infectionPath (환자 정보 파일 경로)
```
예: `./infectionPath patientInfo_sample.txt`

## 결과
- 제공된 샘플 환자 데이터(5명)로 감염 경로를 추적한 결과, 문제에서 제시한 정답과 동일한 전파 경로(예: 2번 환자가 최초 전파자, 0/3/4번은 2번으로부터 전염) 도출을 확인
- 기능 1~4번 모두 정상 동작 확인
